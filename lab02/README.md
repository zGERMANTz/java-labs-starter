# Лабораторная работа 2: Классы и инкапсуляция

Условие: [`assignments/lab02-domain-model.md`](../assignments/lab02-domain-model.md).

## Инварианты

### BankAccount
- Баланс не может быть отрицательным ни при создании, ни после любых операций
- Сумма депозита должна быть положительной
- Сумма снятия должна быть положительной и не превышать текущий баланс

### ProjectTask
- Идентификатор (`id`) не может быть `null` или пустой строкой
- Название (`title`) не может быть `null` или пустой строкой
- Статус (`status`) не может быть `null`
- Оценка трудоемкости (`estimatedHours`) должна быть неотрицательной
- Статус может быть изменен только через метод `changeStatus`
- Увеличение оценки трудоемкости возможно только на положительное число часов
